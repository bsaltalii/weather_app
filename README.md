# 🌤️ Weather App

*Weather App* is a Flutter-based weather forecasting application that delivers real-time weather data based on your location. Track the current conditions, hourly forecasts, and weather updates across multiple cities.

---

## 🎯 Purpose

This app is designed to provide an intuitive, location-aware weather experience.  
With real-time data and forecasts, users can quickly check the weather anywhere, anytime.

---

## 🧩 App Architecture

Structured using best practices for maintainability and scalability:

| 🧱 Layer      | 📌 Description                            |
|--------------|--------------------------------------------|
| *Pages*      | Screens and views in the UI layer          |
| *Widgets*    | Reusable UI components                     |
| *Services*   | Weather data fetch and location handling   |
| *Models*     | Data structures for weather representation |
| *Utils*      | Helper functions and constants             |

---

## 🚀 Features

<ul>
  <li>📍 <strong>Location-Based Forecasts</strong>: Automatically fetches weather for your current location.</li>
  <li>🌡️ <strong>Current Conditions</strong>: Real-time temperature, weather type, and more.</li>
  <li>📆 <strong>Hourly & Daily Forecasts</strong>: Plan ahead with accurate short and long-term forecasts.</li>
  <li>🌐 <strong>Multi-City Support</strong>: View weather data for multiple saved cities.</li>
</ul>

## 📦 Installation

### Prerequisites

•⁠  ⁠Flutter SDK (latest version)  
•⁠  ⁠Dart SDK  
•⁠  ⁠A Flutter-compatible IDE (e.g., VS Code, Android Studio)  
•⁠  ⁠Physical device or emulator

### Steps

```bash
# Clone the repository
git clone https://github.com/bsaltalii/weather_app.git

# Navigate to the project directory
cd weather_app

# Install dependencies
flutter pub get

# Run the app
flutter run
```
